# Chapter 6 Examples

Koleksi lengkap program contoh dari Buku **Chapter 6: Face Detection and Face Recognition**.

## Daftar File Example
- **`example_6_1.py`**: OpenCV face detection pada gambar diam (`face0.jpg`).
- **`example_6_2.py`**: OpenCV face detection real-time via webcam.
- **`example_6_3.py`**: Deteksi wajah dan mata dengan Haar Cascade.
- **`example_6_4.py`**: Deteksi wajah, mata, dan senyuman pada gambar (`face2.jpeg`).
- **`example_6_5.py`**: Deteksi wajah, mata, dan senyuman real-time via webcam.
- **`example_6_6.py`**: Deteksi wajah menggunakan library `face_recognition` & PIL.
- **`example_6_7.py`**: Deteksi 9 landmark wajah (72 titik) dengan `face_recognition`.
- **`example_6_8.py`**: Deteksi landmark wajah real-time via webcam.
- **`example_6_9.py`**: Pengenalan wajah (Face Recognition) webcam dengan model encodings.
- **`example_6_9a.py`**: Pengenalan wajah dari direktori gambar otomatis.
- **`example_6_9b.py`**: Pengenalan wajah webcam real-time dari direktori gambar otomatis.
- **`example_6_10.py`**: Pelatihan model pengenalan wajah OpenCV LBPH (`cv2.face.LBPHFaceRecognizer`).
- **`example_6_11.py`**: Prediksi pengenalan wajah pada gambar dengan model terlatih OpenCV.
- **`example_6_12.py`**: Pengenalan wajah via webcam dengan model OpenCV terlatih.
- **`example_6_13.py`**: Sistem absensi/rekam data wajah mahasiswa berbasis GUI (`PySimpleGUI` + OpenCV).
- **`example_6_14.py`**: Sistem GUI Face Recognition menggunakan library `face_recognition`.
- **`example_6_15.py`**: Demo `DeepFace`: deteksi wajah, verifikasi kemiripan, dan analisis demografi (usia, gender, ras, emosi).
- **`example_6_15a.py`**: Analisis wajah live stream webcam menggunakan `DeepFace.stream()`.
- **`example_6_15b.py`**: Prediksi demografi (usia, gender, ras, emosi) menggunakan model Keras.
- **`example_6_16.py`**: Face Swap foto menggunakan Delaunay Triangulation & OpenCV seamless cloning.
- **`example_6_17.py`**: Face Swap real-time webcam dengan dlib (68 landmark) & `FaceSwap_Utils.py`.
- **`FaceSwap_Utils.py`**: Modul utilitas pemrosesan affine transform & masking untuk Example 6.17.
- **`example_6_18.py`**: Aplikasi web deteksi wajah berbasis Streamlit.
- **`example_6_19.py`**: Aplikasi web deteksi wajah webcam/video dengan slider parameter (Streamlit).
- **`example_6_20.py`**: Aplikasi web kecantikan/filter webcam (brightness, contrast, smoothing) dengan Streamlit.
- **`example_6_21.py`**: Aplikasi web konversi foto menjadi sketsa pensil (Pencil Sketch) dengan Streamlit.
- **`example_6_22.py`**: Face mesh 3D pada foto diam menggunakan MediaPipe FaceMesh.
- **`example_6_23.py`**: Face mesh 3D real-time webcam menggunakan MediaPipe FaceMesh.
- **`chapter6_examples.py`**: Runner/indeks terpadu untuk menjalankan example.
