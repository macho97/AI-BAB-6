# Chapter 6 Exercises

Solusi lengkap latihan dari Buku **Chapter 6: Face Detection and Face Recognition**.

## Daftar File Exercise
- **`exercise_6_1.py`**: Modifikasi Example 6.1 dengan variasi parameter `scaleFactor`, `minNeighbors`, dan `minSize`.
- **`exercise_6_2.py`**: Modifikasi Example 6.2 untuk membaca video dari file (`cv2.VideoCapture('video.mp4')`).
- **`exercise_6_3.py`**: Uji akurasi deteksi wajah dan mata pada berbagai gambar uji.
- **`exercise_6_4.py`**: Uji akurasi deteksi wajah, mata, dan senyuman pada berbagai gambar uji.
- **`exercise_6_5.py`**: Modifikasi Example 6.5 untuk membaca video dari file.
- **`exercise_6_6.py`**: Uji akurasi deteksi wajah pada foto kelompok (multiple faces).
- **`exercise_6_7.py`**: Cetak seluruh nama fitur landmark dan nilai koordinat titiknya.
- **`exercise_6_8.py`**: Tampilkan label teks nama landmark di atas webcam secara real-time.
- **`exercise_6_9.py`**: Pengenalan wajah dengan 10 gambar referensi serta pengukuran performa kecepatan (FPS).
- **`exercise_6_10.py`**: Perbandingan recognizer OpenCV: `LBPH`, `EigenFace`, dan `FisherFace`.
- **`exercise_6_11.py`**: Penambahan field atribut `Address` (Alamat) pada GUI sistem rekam data mahasiswa.
- **`exercise_6_12.py`**: Penambahan input teks pada GUI agar pengguna dapat menentukan nama file database sendiri.
- **`exercise_6_13.py`**: Analisis demografi DeepFace pada berbagai foto wajah.
- **`exercise_6_14.py`**: Prediksi model Keras (usia, gender, etnis, emosi) pada berbagai foto wajah.
- **`exercise_6_15.py`**: Uji pertukaran wajah (Face Swap) pada berbagai pasang foto.
- **`exercise_6_16.py`**: Uji pertukaran wajah webcam dengan template wajah berbeda.
- **`exercise_6_17.py`**: Penambahan tombol "Save Face" pada web app deteksi wajah Streamlit.
- **`exercise_6_18.py`**: Penambahan tombol "Save Face" pada web app webcam Streamlit.
- **`exercise_6_19.py`**: Penambahan slider parameter `kernel_size`, `sigmaX`, `sigmaY` pada web app Pencil Sketch.
- **`exercise_6_20.py`**: Eksekusi MediaPipe FaceMesh pada beberapa file gambar sekaligus (`file_list`).
- **`exercise_6_21.py`**: Pencetakan seluruh koordinat landmark MediaPipe 3D ke konsol.
- **`chapter6_exercises.py`**: Runner/indeks terpadu untuk menjalankan exercise.
